# Ritmo — treino da Aline

Aplicação web responsiva para acompanhar os treinos A e B, com ilustrações e explicações breves de cada exercício.

## Executar localmente

Abra `index.html` ou sirva a pasta com qualquer servidor de arquivos estáticos. Um endereço HTTPS ativa também o funcionamento instalável e o cache offline.

## Dados e privacidade

O avanço das séries é guardado no `localStorage` do navegador e associado à data local do aparelho. Abrir de novo no mesmo dia mantém o avanço; em outro dia, começa do zero. Os dados ficam neste aparelho e não sincronizam entre dispositivos.

## Publicar

O site não precisa de build nem de servidor de aplicação: publique os arquivos desta pasta em qualquer serviço de hospedagem estática. Para usar um domínio próprio, configure-o no serviço de hospedagem escolhido.
